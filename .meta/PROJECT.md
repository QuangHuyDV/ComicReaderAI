# CRAI

Version: 1.0

---

# Overview

CRAI is a desktop application designed to translate image-based reading content such as manga, comics and scanned documents.

The primary objective is to allow users to continue reading naturally without constantly switching between translation tools.

CRAI focuses on speed, readability and extensibility.

---

# Vision

Reading should never be interrupted by language barriers.

CRAI aims to make translated content feel as natural as reading the original.

---

# Goals

Primary goals:

- Fast translation
- Accurate text detection
- High-quality text rendering
- Minimal user interaction
- Extensible architecture

---

# Non Goals

CRAI is not:

- a full image editor
- a general OCR platform
- a cloud document management system
- a replacement for professional DTP software

---

# Target Users

Primary users:

- Manga readers
- Comic readers
- Light novel readers
- Users reading foreign image-based documents

---

# Core Features

- OCR
- Image preprocessing
- Translation
- Text rendering
- Reading mode
- Plugin system

---

# Design Principles

The project values:

Maintainability

Replaceability

Performance

User experience

Long-term evolution

---

# Technology Direction

The exact technology stack may change.

The architecture should allow replacing:

OCR engine

Translation provider

Rendering engine

AI provider

without rewriting the application.
